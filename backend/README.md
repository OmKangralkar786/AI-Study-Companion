# AI Study Companion

An AI-powered study assistant built using Django, React, and Google Gemini API.

## Features

- User Authentication (JWT)
- PDF Upload
- AI Summary Generation
- AI Notes Generation
- AI MCQ Generation
- AI Flashcard Generation
- Interactive Flashcards
- Responsive Dashboard

## Tech Stack

### Frontend
- React.js
- Bootstrap
- Axios
- React Router

### Backend
- Django
- Django REST Framework
- JWT Authentication

### AI
- Google Gemini API
